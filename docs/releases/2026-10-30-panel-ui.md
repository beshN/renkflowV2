# Panel arayüzü yayını

Panel için yeni genel bakış, termin listesi, sipariş grafiği, sidebar ve üst bar. Animate UI geçişi yalnız dashboard yerleşimine bağlanır.

Tema `panel-theme.css` dosyasındadır; tüm seçiciler panel bulunan sayfaya sınırlandırılır. Portal menüleri ve diyaloglar aynı panel temasını alır. Landing, giriş, ortak tema/font tanımları ve paylaşılan UI bileşenlerinin üretimdeki kaynakları değiştirilmez. Native uygulama, API, şema ve migration değişikliği yoktur.
