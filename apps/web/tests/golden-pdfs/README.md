# Altın PDF test seti

Bu klasör gerçek şirket PDF'lerini Git geçmişine almadan test etmeye hazırlanmıştır.

- digital/manifest.json: en az 10 dijital PDF için beklenen alanlar
- scanned/manifest.json: en az 10 taranmış PDF için beklenen alanlar
- PDF dosyaları gizlilik nedeniyle .gitignore ile dışarıda tutulur.
- Manifest girdileri anonimleştirilmiş dosya hash'i, beklenen normalize alanlar ve kritik alan doğruluğunu taşır.

Gerçek test seti şirketten güvenli örnekler alındığında doldurulacak; kritik alan hedefi %85'tir.
