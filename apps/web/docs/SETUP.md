# Web yerel kurulum

Güncel teknoloji yığını, Node sürümü, kurulum ve test-DB komutları kökteki [README](../../../README.md) içindedir. Ortam değişkenleri için [`.env.example`](../.env.example), mevcut kod ile birleşmemiş PR ayrımı için [DEV_HANDOFF](../../../docs/DEV_HANDOFF.md) kullanın.

Bu dosyadaki eski Cloud Run / Cloud SQL / GCS talimatları güncel web kurulumu için geçerli değildir. Yayınlama bilgisi ayrı [Vercel runbook](vercel-deployment.md) içindedir; yerel kurulum için canlı DB'ye migration veya seed uygulanmaz. AI çıktıları insan incelemesi ve onayı gerektirir.
